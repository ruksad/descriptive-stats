# Machine Learning Questions - Summary

## Overview
This document provides a comprehensive set of Machine Learning questions designed for students to practice and assess their understanding of key ML concepts covered in the course.

## File Added
- **ML_Questions.ipynb** - A Jupyter notebook containing 155+ questions across 14 sections plus bonus material

## Content Structure

The notebook covers the following major topics:

### 1. **Clustering** (25 marks)
   - Conceptual questions on K-Means, hierarchical clustering, DBSCAN
   - Practical exercises using scikit-learn
   - Evaluation metrics (inertia, silhouette score)

### 2. **Linear Regression** (25 marks)
   - Theory: assumptions, cost functions, gradient descent
   - Practical implementation with scikit-learn
   - Regularization techniques (Ridge and Lasso)

### 3. **Feature Engineering & Encoding** (20 marks)
   - Various encoding techniques (Label, One-Hot, Ordinal, Target)
   - Feature scaling (normalization vs standardization)
   - Handling missing values
   - Polynomial features

### 4. **Classification** (25 marks)
   - Multiple algorithms: Logistic Regression, Decision Trees, Random Forest, SVM, KNN
   - Evaluation metrics: Confusion Matrix, Accuracy, Precision, Recall, F1-Score
   - ROC curves and AUC
   - Cross-validation techniques

### 5. **Text Processing & NLP** (25 marks)
   - Text preprocessing and tokenization
   - Bag of Words and TF-IDF
   - Word embeddings (Word2Vec, GloVe)
   - Document embeddings

### 6. **Model Evaluation & Validation** (10 marks)
   - Train/validation/test splits
   - Cross-validation strategies
   - Hyperparameter tuning
   - Learning curves

### 7. **Advanced Topics** (10 marks)
   - Dimensionality reduction (PCA, t-SNE)
   - Transfer learning
   - Anomaly detection
   - AutoML concepts

### 8. **Case Studies** (20 marks)
   Four real-world scenarios:
   - Customer Segmentation
   - Fraud Detection
   - House Price Prediction
   - Sentiment Analysis

### 9. **Implementation Project** (30 marks)
   Three project options:
   - End-to-End Classification Pipeline
   - Clustering Analysis with Visualization
   - Text Classification System

### 10. **Bonus: Debugging** (5 marks)
   Five code snippets with intentional errors for students to identify and fix

1. Work through sections sequentially

5. Test all code before submission
